# VALORANT League Manager

### Reyna 공식 규칙 반영

Reyna의 Devour와 Dismiss는 별도 구매 횟수가 아니라 최대 2개의 `Soul Harvest` 자원을 함께 소비한다. Reyna가 마지막 3초 안에 피해를 준 적이 사망하면 해당 Reyna에게만 사용할 수 있는 Soul Orb가 3초 동안 생성된다.

Devour는 구슬 하나를 소비해 2초 동안 총 50을 회복한다. 100 HP를 넘는 양은 최대 총 생존력 150까지 과치유로 전환되며, 일반 상태에서는 마지막 회복 시점부터 10초 동안만 유지된다. Empress 중 Devour와 자동 회복은 라운드가 끝날 때까지 유지된다. Dismiss는 구슬 하나를 소비해 1.5초 동안 피해를 받지 않고 최대 12m/s로 전투 위치를 이탈하며, Empress 중에는 은신 상태로 진단된다.

Leer는 100 HP를 가진 파괴 가능한 시야 방해 오브젝트다. 활성 범위의 적에게 현행 공통 근시 거리인 7m를 적용한다. Empress는 7 궁극기 포인트를 소비하며 사망 또는 라운드 종료까지 유지되고, 공통 Stim 수치인 발사 속도 1.1, 재장전 0.9, 무기 전환 0.9, 반동 회복 1.1을 적용한다.

### Iso 공식 규칙 반영

Iso는 Contingency, Undercut, Double Tap, Kill Contract를 독립적인 전투 상태로 처리한다. Contingency는 앞으로 이동하면서 탄환만 차단하고 시야는 유지한다. 느린 전개가 필요한 상황에서는 같은 지속시간 동안 절반 속도로 이동한다.

Undercut은 벽을 통과하는 직선 투사체로, 경로상의 아군과 적 모두에게 4초 동안 취약과 제압을 적용한다. Double Tap은 1초 동안 무기를 사용할 수 없는 준비 동작 뒤 보호막을 얻는다. 보호막은 피해량과 관계없이 한 번의 피해를 막고 사라지며, 활성 시간 중 처치하거나 피해를 준 적이 쓰러지면 3초 동안 에너지 오브가 생성된다. 오브를 사격하면 보호막과 활성 시간이 12초로 갱신된다.

Kill Contract는 최대 36m 경로에서 처음 맞은 적과 Iso를 외부 교전으로부터 격리한다. 결투 동안의 임시 상태는 종료 뒤 원래 위치와 체력·보호막으로 복원되며 패자는 실제 처치로 기록된다. 궁극기 결투에서 Iso가 이기면 Double Tap 활성 조건을 자동으로 갖춰 오브가 생성될 수 있다. 고정 시드 검증에는 Iso 전용 Icebox 맵을 추가해 전체 생명주기를 검사한다.

VCT 데이터를 기반으로 선수와 팀을 운영하고 경기를 시뮬레이션하는 VALORANT 매니지먼트 게임 프로젝트다. Football Manager처럼 팀 선택, 선수 능력치와 역할·요원 숙련도 확인, 맵 비토, 조합 선택, 경기 진행, 시즌 순위와 통계 확인을 하나의 흐름으로 만드는 것이 목표다.

현재 게임은 2026 VCT 국제 리그 48팀을 기준으로 한다. 선수 데이터는 여러 시즌의 객관적 경기 기록을 사용하며, 2026 표본이 적은 선수는 과거의 검증된 기록과 신뢰도를 함께 사용한다.

## 데이터 구조

데이터는 원본 보존 계층과 게임 소비 계층을 분리한다.

1. `stats/`: 원본 CSV
2. `vct_json/`: CSV 행을 손실 없이 변환한 ID 기반 JSONL
3. `profile_json/`: 선수·팀·맵·요원의 객관적 집계 프로필
4. `stat_json/`: 프로필을 11개 능력치와 숙련도로 변환
5. `runtime_2026/`: 여러 시즌을 결합한 2026 게임용 선수 데이터
6. `history_json/`: UI에서 보여주는 연도·대회별 선수 기록
7. `src/data/`: 브라우저에서 직접 사용하는 런타임 JSON

`vct_json/data`, `profile_json/data`, `stat_json/data`는 재생성 가능한 대용량 결과물이므로 Git에서 제외되어 있다. 스크립트, 설정, 스키마, 매니페스트와 검증 보고서는 보존한다.

### UI 없는 경기 시뮬레이션

`src/core/match-engine.js`의 `simulateMatch()`는 DOM 없이 Bo1, Bo3, Bo5 전체를 실행한다. 등록 선수단에서 출전 5인이 정해진 팀 객체와 seed를 전달하며, 필요하면 맵·진영·요원 조합을 직접 지정할 수 있다.

```js
const result = simulateMatch({
  home,
  away,
  seed: 'season-2026-week-1-match-3',
  bestOf: 3,
  maps: ['Ascent', 'Bind', 'Haven']
});
```

반환값에는 매치 승자, 맵 스코어, 라운드 차이, 맵별 seed, 전체 라운드 로그, 선수 박스스코어와 Rating이 포함된다.

### 팀 단위 요원 조합

자동 드래프트는 선수별 최고 숙련 요원을 독립적으로 선택하지 않는다. 각 선수의 상위 후보를 조합해 요원 중복 없이 팀 전체 점수가 가장 높은 구성을 찾는다. 평가는 개인 숙련도, 역할 숙련도, 맵 선호, 전략별 요원 기능 벡터와 역할 커버리지를 함께 사용한다.

사용자가 직접 만든 조합도 같은 평가 함수를 사용한다. 중복 요원이나 전략가·척후대 등 핵심 역할 부재는 `violations`와 수치 페널티로 반환된다. 조합 관련 후보 수·가중치·페널티는 `src/core/simulation-model.js`의 `COMPOSITION_MODEL`에서 조정한다.

### 경제 상태

경제 계산은 `src/core/economy.js`, 수치 조정은 `src/core/economy-model.js`로 분리한다. 라운드마다 구매 전 크레딧, 구매 종류와 지출, 라운드 수입, 연패 단계와 다음 크레딧을 로그에 저장한다. 승리 수입, 단계별 패배 보너스, 스파이크 설치 보너스, 하프타임·연장 초기화와 크레딧 상한을 지원한다. 화면 중계와 UI 없는 경기 엔진은 같은 라운드 경제 로그를 사용한다.

### 시뮬레이션 분포 검증

`runtime_2026/scripts/validate-simulation-balance.mjs`는 모든 팀이 포함되는 순환 표본을 만들고 평균 라운드 수, 연장 비율, 전력 차가 있는 경기의 업셋 비율, 팀별 승률·라운드 득실과 선수 Rating·K/D 분포를 저장한다. 오류 허용 범위와 밸런스 권장 범위는 `runtime_2026/simulation-validation-config.json`에서 따로 조정한다.

```powershell
npm run validate:simulation
node .\runtime_2026\scripts\validate-simulation-balance.mjs --matches=10000 --best-of=3 --seed=balance-v2
```

결과는 `runtime_2026/data/simulation-validation.json`에 저장된다. 같은 seed를 사용하면 계산식 변경 전후를 같은 대진으로 비교할 수 있다.

### 경기 형식과 비토

리그 기본값은 Bo3이며 `ST.matchBestOf`에 저장된다. 특정 일정 객체에 `bestOf: 1`, `bestOf: 3`, `bestOf: 5`를 지정하면 해당 경기만 형식을 덮어쓴다. 형식별 승리 조건과 비토 순서는 `src/core/match-format.js`에서 관리한다.

- Bo1: 6밴, 남은 1맵
- Bo3: 4밴·2픽·디사이더, 2맵 선승
- Bo5: 2밴·4픽·디사이더, 3맵 선승

## 능력치 모델

게임은 다음 11개 능력치를 사용한다.

- Firepower
- Combat Efficiency
- Entry
- Positioning
- Teamplay
- Tactical
- Clutch
- Explosiveness
- Consistency
- Adaptability
- Pressure

점수는 다른 선수 집단의 상대 순위만으로 정하지 않고 고정된 절대 기준점으로 변환한다. 표본이 적으면 무조건 낮은 점수를 주지 않고 중립값에 수축하며, 신뢰도를 별도로 보존한다. ACS는 원본과 기록 화면에는 유지하지만 능력치 계산에서는 ADR, 킬, 첫 교전, 멀티킬 등과 중복되므로 핵심 입력에서 제외한다.

세부 계산식은 다음 파일에 있다.

- `stat_json/FORMULAS.md`
- `stat_json/config/rating-model.json`
- `runtime_2026/config.json`

## 현재 중요한 제한 사항

- 2026 출전 기록은 계약 명단이 아니므로 일부 선수의 팀 소유권이 중복되어 있다.
- 현재 플레이 가능 맵은 정밀 구역·시야·벽 판정을 수동 검증한 어센트 하나다. Bo3·Bo5 엔진은 유지되므로 임시로 어센트를 반복 사용한다.
- 다른 맵의 에셋과 기본 좌표는 삭제하지 않았으며 맵 진단실에서 `검증 대기` 상태로 열어 세부 전술 지점을 계속 교정할 수 있다.
- 수비의 무정보 상황 정보 획득, 설치 후 움직임과 스킬 사용 판단은 아직 고도화 중이다.
- 경제와 장비 구매는 실제 VALORANT보다 단순하다.
- 진행 중인 인메모리 경기는 아직 영구 세이브에 포함되지 않는다.

구체적인 해결 순서와 완료 조건은 `PLAN.md`를 따른다.

## 구현 현황

### 데이터와 선수 모델

- 원본 CSV를 손실 없이 JSONL로 변환하고 선수·팀·대회·요원 ID로 연결한다.
- 원본 프로필, 계산 능력치, 2026 게임 런타임과 표시용 역사를 서로 분리한다.
- 표본 신뢰도와 시즌 감쇠를 적용하며 요원 경험은 최근 여러 시즌을 완만하게 결합한다.
- 11개 게임 능력치, 역할·요원·맵 숙련도와 플레이 성향을 제공한다.
- 2026 로스터는 `runtime_2026/roster-overrides-2026.json`을 편집한 뒤 재생성할 수 있다.

### 경기와 시즌

- 고정 seed 기반 Bo1·Bo3·Bo5 경기, 맵 비토와 팀 단위 요원 조합을 지원한다.
- 라운드별 경제, 구매, 스킬 구매, 스파이크 설치·해체, 연장과 타임아웃을 처리한다.
- 정규시즌 일정, 순위, 경기 아카이브와 더블 엘리미네이션 플레이오프를 제공한다.
- 사용자 경기는 한 라운드씩 계산하며 같은 엔진으로 UI 없는 빠른 경기도 실행한다.

### 공간 시뮬레이션과 교전

- 10명의 선수가 0.1초 틱마다 인지·판단·행동하며 같은 틱의 공격은 동시 판정한다.
- 걷기와 뛰기, 50m 달리기 발소리, 시야, 벽, 경로 탐색과 엄폐 이동을 지원한다.
- 발소리는 맵 의미 구역을 기준으로 이동 방향, 접근·이탈, 거리와 신뢰도를 기록한다.
- 무기별 피해, 거리, 명중 부위, 헤드샷, 방어구, 집중 사격과 트레이드 창을 처리한다.
- 어센트는 모든 이동 가능 좌표에 의미 구역이 할당되어 있으며 구역 중복과 미할당을 자동 검사한다.
- Bind, Haven, Split, Lotus, Sunset, Icebox에도 이동 좌표·경로·시야 검증용 맵 데이터가 있다.
- 본 라운드, 설치, 폭발과 해체는 하나의 공용 시계를 사용하며 해체 절반 체크포인트를 지원한다.
- 설치 후 수비는 한 번에 같은 경로를 받지 않고 디퓨저와 클리어 역할별 경로·출발 시각을 배정받는다.
- 폭발이 임박하면 해체 가능성을 판단해 탈출하며, 폭발 범위 안에 남은 선수는 스파이크 사망으로 기록된다.

### 팀 판단과 소통

- 선수별 규율, 인지, 협력, 공격성, 침착성을 사용하는 판단 타임라인을 보존한다.
- 선수는 적 발견, 발소리, 아군 사망, 스킬 준비와 사용 상태를 팀에 보고한다.
- 선수 제안은 통신 지연 후 IGL에게 전달되며 IGL이 승인·거절·보류·복귀를 판단한다.
- `FIVE`, `ONE_FOUR`, `ONE_THREE_ONE`, `TWO_THREE` 공격 대형을 지원한다.
- 공격은 정보 수집, 스킬 대기, 사이트 확정, 전환, 재집결과 후설치 상태를 사용한다.
- 공격 진입 시 엔트리, 세컨드 엔트리, 스킬 지원, 스파이크 운반, 후방 경계가 서로 다른 집결 좌표와 목적지를 사용한다.
- 집결과 스킬 준비가 끝나면 역할별 시간차를 두고 진입하며, 앞선 선수와의 거리에 따라 대기하거나 따라붙는다.
- 엔트리가 사망하면 다음 생존자가 선두 임무를 승계하고, 역할·집결점·목적지·출발 시각이 진단 타임라인에 기록된다.
- 수비는 사이트 앵커를 유지하면서 정보 확실도에 따라 제한된 인원만 지원하고, 설치 확정 후 전원 리테이크할 수 있다.
- 인포가 없을 때 수비는 전술 성향과 배치를 근거로 짧은 피킹, 정찰 스킬 확인 또는 2인 공간 장악을 선택하고 접촉·시간 조건에 따라 앵커로 복귀한다.

### 스킬 판단과 생명주기

- 비설치 스킬은 라운드 시작 3초 전에 사용할 수 없으며, 단순 시간 경과만으로 강제 사용하지 않는다.
- 정보 확인, 진입, 교전, 사이트 지연, 리테이크, 후설치와 회복 상황에 따라 스킬 사용 목적을 따로 판단한다.
- 실제로 발동하지 못한 구매 스킬과 궁극기 계획은 라운드 종료 시 환급하고, 실제 사용된 경우에만 소비한다.
- 설치형 스킬은 준비·활성·소멸·파괴 시점을 보존하며 파괴 후 재충전 스킬은 파괴 시점부터 쿨다운을 계산한다.
- 일시정지는 시뮬레이션 시간이 아니라 관전 재생 시간만 멈추는 구조이며, 정지 중에는 스킬 지속시간과 쿨다운이 진행되지 않는다.
- 진단 보고서에서 계획 당시 판단, 실제 사용 맥락, 사용하지 않아 복원된 스킬과 오브젝트 생명주기를 확인할 수 있다.

### 교전·엄폐·트레이드

- 같은 틱에 선택된 사격은 병렬로 처리하여 먼저 계산된 사망 때문에 이미 결정된 반격이 취소되지 않는다.
- 두 명 이상에게 노출된 선수는 주변 이동 가능 좌표의 시야를 비교해 더 안전한 엄폐로 이동한다.
- 엄폐 후에는 침착성에 따른 재정비 시간을 가진 뒤 기존 임무 경로로 재피킹한다.
- 무기별 거리 구간, 명중 부위, 연사 간격과 선수 헤드샷 기록을 실제 피해 계산에 연결한다.
- 여러 선수가 같은 적을 보고 사격하면 집중 사격 압박을 적용하며, 크로스파이어와 고립 여부가 명중 계산에 반영된다.
- 팀원이 사망하면 거리·시야·팀워크에 따라 트레이드 창을 만들고 해당 시간 안의 후속 사격에 보정을 적용한다.
- 진단 데이터에는 엄폐 목적지와 재피킹 시각, 트레이드 지원자·만료 시각, 집중 사격 수와 교전 보정 근거가 남는다.

### 경제와 장비

- 선수별 크레딧을 독립적으로 관리하며 권총, 에코, 강제 구매, 세미 바이, 풀 바이와 보너스 라운드를 구분한다.
- 무기·방어구·스킬은 하나의 선수 계정에서 실제 가격만큼 차감하며 최대 9,000 크레딧과 연패 보너스를 적용한다.
- 팀원의 총기 드롭은 구매 단계 내 판매·환불 후 처리하여 이미 산 저가 무기 비용이 이중 지출되지 않는다.
- 생존자는 무기와 남은 방어구를 다음 라운드로 가져가고, 사망자는 장비를 잃는다. 진영 교대와 연장에서는 장비와 크레딧을 규칙에 맞게 초기화한다.
- 보유 총기와 방어구 가치가 높고 리테이크 승산이 낮으면 IGL이 세이브를 선택하며, 선수들은 서로 다른 안전 위치로 실제 이탈한다.
- HUD는 엔진이 계산한 무기·방어구·잔여 크레딧을 사용하고, 진단 보고서는 구매 전·구매 후·수입 후 크레딧, 드롭과 보존 장비를 분리해 보여준다.

### 관전과 진단

- 감독 모드가 기본이며 하단에서 내가 지휘하는 팀의 보고·제안·IGL 명령·수행 콜을 확인한다.
- 최근 팀 음성은 펼쳐볼 수 있는 라운드 로그에 누적되며 일시정지 중에도 다시 확인할 수 있다.
- IGL 명령과 이후 3초간의 실제 선수 판단이 맞지 않으면 진단 보고서에 불일치 경고를 남긴다.
- 재생, 한 라운드 진행, 라운드 건너뛰기, 일시정지와 1·2·4배속을 지원한다.
- 전투 확대, 선수 HUD, 라운드 결과와 로컬 맵·요원·무기·방어구 이미지를 제공한다.
- `CODEX DIAGNOSTIC`은 seed, 좌표, 사건, 선수 판단, 팀 정보, IGL 상태, 진입 계획과 발소리 방향을 JSON으로 출력한다.
- 맵 진단실에서 맵별 영역 오버레이, 경로와 두 지점 사이 시야를 검사할 수 있다.

### 맵 전술 좌표

- Ascent, Bind, Haven, Split, Lotus, Sunset, Icebox 모두 160×160 이동 격자와 벽 기반 시야 검사를 사용한다.
- 모든 이동 가능 셀은 하나의 의미 구역에 배정되며, 2사이트 맵은 최소 11개, 3사이트 맵은 최소 15개의 사이트·메인·로비·연결부·중앙·진영 구역을 제공한다.
- 로컬 전술 PNG의 설치 가능 색상에서 사이트별 실제 설치 영역 중심과 크기를 추출했다.
- 모든 사이트는 공격 집결점 5개, 진입점, 정보 피킹점, 수비 홀드점과 후설치 위치를 같은 형식으로 제공한다.
- 집결점은 화면 방향 고정 오프셋이 아니라 실제 이동 가능한 진입 경로 위에서 추출해 벽 안에서 한 좌표로 합쳐지지 않는다.
- 맵 검증은 미할당·빈 의미 구역, 전술 좌표 도달 가능성, 설치 영역, 오브·배리어, 좌표 범위와 시야 대칭성을 검사한다.

## 현재 경기 엔진 상태

경기 엔진은 Bo1, Bo3, Bo5를 지원하며 리그 경기의 기본 형식은 Bo3이다. 맵 비토, 선발 5인, 요원 조합, 선수 능력치, 진영, 경제, 맵 지형과 전술 성향을 이용해 라운드를 계산한다. 라운드에는 페이즈별 이동과 교전, 첫 교전, 트레이드, 크로스파이어, 스파이크 설치·해체와 클러치 기록이 포함된다.

사용자 관전 경기는 맵을 미리 끝까지 계산한 뒤 재생하지 않는다. `MATCH.mapSimulation`에 진행 중인 맵 상태를 메모리로 보관하고, 이전 라운드의 점수·경제·전술 적응 상태를 이어받아 다음 라운드를 하나씩 계산한다. 빠른 경기와 UI 없는 백그라운드 경기는 같은 라운드 엔진을 일괄 실행한다.

현재 이 인메모리 상태는 세이브 데이터가 아니다. 브라우저를 새로고침하거나 앱을 종료하면 진행 중인 경기는 사라진다. 시즌 진행 저장은 추후 버전이 있는 JSON 세이브로 추가하며, 현 단계에서는 SQLite를 사용하지 않는다.

### 경기 엔진 검증

```powershell
npm run verify:rng
npm run verify:incremental
npm run verify:boxscore
npm run verify:match-engine
npm run verify:economy
npm run verify:tactics
npm run verify:phases
npm run validate:simulation
npm run validate:vct-distributions
```

`verify:incremental`은 같은 seed로 맵 전체를 즉시 계산한 결과와 한 라운드씩 계산한 결과가 일치하는지 확인한다. UI 렌더링이나 대기 중에 다른 난수가 사용되더라도 다음 라운드 결과가 달라지지 않는 것도 함께 검사한다.

`verify:boxscore`는 공간 교전 이벤트에서 K, D, A, 피해량, 생존과 트레이드를 집계해 ACS, ADR, KAST, KPR, APR, K:D와 FK:FD가 일관되게 계산되는지 검사한다. Rating은 이 지표들을 함께 사용하는 게임 내부 영향력 지표이며 VLR의 비공개 공식을 그대로 복제한 값은 아니다.

`validate:vct-distributions`는 2023~2026년 `stats` CSV의 실제 VCT 표본과 고정 시드 시뮬레이션을 비교한다. 실제 표본의 맵 라운드 수, 연장률, 승리 방식, 선수 Rating·ACS·KAST·ADR·KPR·APR·FKPR·FDPR·K:D·헤드샷 비율과 구매 구간별 승률을 집계하며, 결과는 `runtime_2026/data/vct-distribution-validation.json`에 저장한다. 기본 비교 표본은 40경기이고 다음처럼 변경할 수 있다.

```powershell
npm run validate:vct-distributions -- --matches=100
```

초기 기준선은 실제 4,097맵·86,877라운드와 시뮬레이션 40맵을 비교했다. 첫 검증에서 실제 HS%와 킬 헤드샷 비율을 잘못 비교하던 정의를 바로잡았고, 선수의 실제 적중 HS%를 중심으로 작은 능력치 보정만 적용하도록 명중 부위 계산을 교정했다. 어시스트는 최근 10초 내 50 이상 피해 또는 유효한 보조 스킬 영향으로 판정하며 한 킬에 여러 선수가 기여할 수 있다.

첫 교전 통계 교정 후 40맵 기준 16개 비교 지표 중 12개가 통과했고 헤드샷 비율과 APR은 실제 분포 범위에 들어왔다. 검증기는 결과를 강제로 보정하지 않으며 차이와 원인 후보만 보고한다.

포스트플랜트는 클리어 담당이 먼저 진입하고 전담 해체자가 뒤따르는 순서로 진행된다. 전담 해체자는 거리뿐 아니라 체력과 오브젝트 수행 능력을 함께 평가해 선택하며, 시작한 해체자가 살아 있는 동안 다른 선수로 매 틱 교체되지 않는다. 해체 중에는 사격을 동시에 수행하지 않고, 수적 열세와 남은 시간을 함께 만족할 때만 장비 세이브로 전환한다. 세이브 후 리테이크가 다시 호출되면 진입 경로를 복구한다.

이 교정으로 40맵 표본의 폭발 승리는 28.0%에서 4.9%, 해체 승리는 7.8%에서 10.4%로 바뀌었고 16개 지표 중 13개가 통과했다. 다만 전멸 승리가 실제 65.0%보다 높은 80.6%라서, 다음 단계에서는 결과 비율을 직접 조절하지 않고 비치명 피해·교전 지속 시간·불리한 교전 이탈 판단을 함께 교정한다.

교전 이탈 판단은 현재 체력·보호막, 시작 장비, 가시 적 수, 팀 전체 수적 열세와 포스트플랜트 임무를 함께 본다. 저체력 또는 다중 노출 선수는 가까운 이동 가능 좌표 중 적 시야가 더 적은 엄폐를 찾으며, 리테이크 클리어 담당과 해체 담당은 자신의 임무를 우선한다. 결정적인 사격이 빗나간 버스트에도 제한적인 비치명 몸통 피해가 발생할 수 있고, 이 피해와 교전 이탈은 진단 보고서에 별도 집계된다.

이탈 교정 후 한 차례 40맵 기준 비교에서는 통과 13개·경고 3개까지 도달했다. 이후 총기 교전을 실제 버스트 단위로 바꾸면서 각 탄환이 명중 여부, 명중 부위와 피해를 독립적으로 판정하도록 확장했다. `shot` 이벤트에는 발사·명중 탄 수를 요약하고 실제 피해는 탄환별 `damage` 이벤트로 남긴다. 피해형 스킬도 시전자, 스킬명과 피해량을 기록하고 해당 피해로 사망하면 킬 원인과 어시스트 원장에 연결한다.

현재 피해 수치가 검증된 일부 요원 스킬부터 실제 피해를 적용한다. 모든 요원의 피해·회복·지속 피해가 완성된 상태는 아니며, 알 수 없는 값을 임의의 비치명 피해로 채우지 않는다. 다중 탄환 적용 후 40맵 비교는 통과 13개·경고 2개·실패 1개이며 ADR 94.6, 전멸 승리 81.0%, 해체 승리 9.9%다. 따라서 다음 교정 대상은 단계형 리테이크와 남은 요원별 실제 스킬 규칙이다.

리테이크에서는 클리어 담당이 먼저 서로 다른 사이트 위치로 진입하고 전담 해체자는 후방 스테이징 지점에서 대기한다. 클리어 담당이 사이트에 도달하거나 교전이 발생하면 해체자를 스파이크로 보내며, 시간이 부족할 때만 시계 판단으로 즉시 진입한다. `retakePlan`과 `retakeDefuserRelease` 이벤트에 역할, 목적지와 해제 근거를 기록해 이 순서를 회귀 검증한다.

팀 전력 차이는 선수 능력, 요원·역할·맵 숙련도, 조합, 진영과 경제를 합쳐 계산한다. 이 값이 공간 교전에 전달만 되고 사용되지 않던 문제를 수정했지만, 큰 명중률 보정은 경제 스노우볼과 결합해 접전을 지나치게 줄였다. 따라서 개인 숙련도는 기존 `experienceModifier`로 직접 반영하고 팀 전력은 교전 명중률에 최대 ±1%의 미세 보정만 준다. 40맵 회귀에서 평균 라운드는 845로 기존 기준선 861에 가깝고 연장률 경고도 발생하지 않았다.

민감도 검증은 같은 seed의 낮음·높음 결과를 쌍으로 비교한다. 평균 차이뿐 아니라 paired 표준오차와 계산식의 구조적 연결도 함께 검사해, 작은 효과의 표본 흔들림과 실제 미연결 버그를 구분한다. 요원 숙련도 검증에서는 낮은 팀의 평균 라운드 득실 `+0.875`, 높은 팀 `+2.625`, 모델 연결 신호 `+26.25`로 통과했다.

실제로 사용된 회복 스킬은 최대 체력 100 안에서 HP를 복구하고 `abilityHeal` 이벤트를 남긴다. 플래시·연막·정찰·기절 등 실제 사용된 유틸리티는 활성 시간과 위치 안에서만 제한된 교전 보정을 주며 `shot.utilityCombatEdge`로 확인할 수 있다. 해체 중에는 주변 클리어 담당 수에 따라 공격자의 노출 사격에 최대 6%의 압박 보정이 적용된다.

세이브 판단과 실행 조건이 달라 IGL이 이른 `SAVE` 상태에 고정되던 문제를 수정했다. 현재는 1v5이거나 수적 열세와 남은 시간이 함께 실제 세이브 조건을 만족할 때만 장비를 보존한다. 클리어 담당의 리테이크 보정은 고정값이 아니라 20 거리 안에서 함께 진입하는 동료 수에 따라 최대 18%까지 적용된다. 40맵 고정 seed 결과는 16개 비교 항목 중 통과 14개·경고 2개·실패 0개이며 전멸 승리 72.7%, 폭발 승리 12.7%, 해체 승리 10.5%, ADR 93.9다.

검증 보고서는 설치 순간 공격·수비 생존 인원을 `4v2` 같은 형식으로 나누고 각 상황의 해체·전멸·폭발·세이브 결과를 `simulation.postPlant.byPlantNumbers`에 기록한다. 수비가 우세한 `1v2`, `2v3`, `3v4`에서는 해체 성공률이 50~79%지만 가장 흔한 설치 상황은 공격 우세 `4v1`, `4v2`, `5v3`, `5v2`다. 따라서 다음 교정 대상은 해체 버튼 자체가 아니라 설치 전에 사이트 수비가 전멸하지 않고 공간을 양보하는 판단이다.

설치 전 사이트 수비가 수적으로 밀리고 노출이 매우 크거나 팀 전술이 `PASSIVE`·`RETAKE`일 때는 무리한 홀드 대신 수비 진영 쪽 재진입 지점으로 물러난다. 이 판단은 `siteConcede` 이벤트에 출발점·목적지·근거를 남긴다. 공격팀도 사이트가 확보된 뒤 멀리 퇴각한 수비수를 끝까지 추격하지 않고 설치 지점으로 복귀한다. 모든 `STANDARD` 수비까지 양보 대상을 넓히는 방식은 별도 검증에서 해체율을 다시 낮춰 채택하지 않았다.

제한적인 사이트 양보를 적용한 40맵 고정 seed 검증은 통과 13개·경고 3개·실패 0개다. 해체 승리는 약 12.0%, 전멸 승리는 약 69%까지 개선됐다. ADR 약 93.7과 APR 약 0.243, 해체 승률은 여전히 경고 범위다.

각 양보 판단에는 사이트 앵커 여부, 팀이 확인한 공격 인원, 가장 빠른 백업 ETA와 3초 안에 도착할 지원 인원을 함께 계산한다. 이 값은 `siteConcede` 이벤트와 선수 판단 타임라인에 기록되어 CODEX DIAGNOSTIC에서 확인할 수 있다. `STANDARD` 수비까지 양보를 넓히거나 백업 ETA를 양보 허용 조건으로 사용한 실험은 해체 승리를 10.0~10.2%로 낮춰 되돌렸다. 따라서 다음 교정에서는 앵커를 더 빨리 후퇴시키지 않고 이 정보를 지원 수비의 출발·경로·도착 판단에 사용한다.

지원 로테이션은 `defenseRotation.assignments`에 각 선수의 출발 구역과 내비게이션 경로 기준 예상 도착 시간을 기록한다. 확인된 공격 인원과 해당 콜에서 허용한 지원 인원 수도 함께 남긴다. 다중 접촉만으로 두 번째 수비수를 조기에 보내는 실험은 해체 승리를 9.2%로, 경로 ETA만으로 지원자를 고르는 실험은 10.0%로 낮춰 모두 철회했다. 현재는 중앙 역할을 우선하고 반대 사이트의 마지막 앵커를 남기는 기존 선택 규칙을 유지한다. 최종 40맵 검증은 통과 13개·경고 3개·실패 0개이며 전멸 69.1%, 폭발 13.7%, 해체 12.3%, 시간 종료 5.0%다.

일반 접촉에 출발한 첫 지원자는 사이트로 곧장 진입하지 않고 경로의 72% 지점에 만들어진 외곽 합류 위치에서 기다린다. 사이트 앵커가 18 거리 안에 도착하면 `defenseSupportRelease`와 함께 두 선수가 재진입하고, 정보가 7초 이상 갱신되지 않으면 `defenseSupportCancel`을 남기고 원래 수비 위치로 복귀한다. 확정 설치와 아군 사망처럼 긴급한 콜은 대기 단계를 생략한다. 합류 위치 도착은 `defenseSupportStage`에 이동 시간과 함께 기록된다.

거리 기반 합류를 적용한 최종 40맵·811라운드 검증은 통과 15개·경고 1개·실패 0개다. 전멸 69.3%, 폭발 13.9%, 해체 13.1%, 시간 종료 3.7%이며 평균 라운드는 20.28, 연장률은 12.5%다. 설치 라운드의 해체 시작률은 40.1%, 시작 후 성공률은 49.8%다. 승리 방식과 APR 경고가 해소됐고 현재 남은 분포 경고는 ADR 93.2다.

Killjoy Nanoswarm은 초당 45 피해와 5초 지속을 갖는 실제 범위 피해로 동작한다. 활성 순간 한 번에 45 피해를 주던 기존 처리를 제거하고 공용 0.1초 시뮬레이션 틱마다 범위 안의 모든 적에게 피해를 적용한다. 검은 벽을 사이에 둔 대상에게는 피해가 전달되지 않으며, Killjoy가 사망하면 남은 틱도 중단된다. 생존자는 첫 피해를 인지하면 `abilityHazardEscape` 판단과 함께 범위 밖의 가장 가까운 이동 가능 지점으로 달려간다.

4맵 에이전트 회귀에서는 Nanoswarm 지속 피해 52틱·229.5 피해와 위험 지역 이탈 9회를 확인했다. 적용 후 40맵 분포는 통과 15개·경고 1개·실패 0개이며 전멸 69.9%, 폭발 13.6%, 해체 13.1%, 시간 종료 3.5%다. 전체 요원 피해 이벤트는 655회·6,109 피해였고 남은 분포 경고는 ADR 93.7이다.

Killjoy Turret은 배치 방향의 전방 180도와 40m 안에서 벽으로 가려지지 않은 가장 가까운 적을 선택해 3발 점사한다. 거리별 1발 피해는 20m 이하 8, 35m 이하 6, 그 이상 4이며 적중 시 0.6초 동안 이동 속도를 50%로 낮춘다. 배치 순간의 범용 18 피해가 공격측 Turret에만 중복 적용되던 오류도 제거해, 실제 점사만 피해로 집계한다.

Turret 체력 100, Killjoy와 40m 이탈 시 비활성, 복귀 후 2초 재활성, 파괴 시 60초 재사용 대기는 공식 패치 수치다. 2026년 공식 패치에는 연사속도 50% 증가만 공개돼 점사 간 정확한 시간은 알 수 없으므로, 게임 모델은 0.75초를 조정 가능한 상수로 사용한다. 4맵 회귀에서 점사 10회·240 피해, 거리 이탈 비활성 3회와 재활성 1회를 확인했다.

Turret 적용 후 최종 40맵·819라운드 검증은 통과 14개·경고 2개·실패 0개다. 전멸 70.7%, 폭발 13.4%, 해체 12.0%, 시간 종료 3.9%이며 요원 피해는 835회·9,317이다. 해체 승리와 ADR 93.6이 경고 범위이므로 Alarmbot까지 구현한 뒤 Killjoy 전체 유틸리티 기여와 리테이크 상호작용을 다시 함께 교정한다.

Killjoy Alarmbot은 7m 안에 들어온 가장 가까운 적을 획득하고 내비게이션 경로를 따라 추적한다. Killjoy가 40m 밖으로 벗어나거나 사망하면 작동하지 않고, 범위에 복귀하면 2초 준비 후 다시 활성화된다. 목표에 도달하면 주변 적에게 취약을 부여하며, 취약 중에는 총기·Turret·지속 피해를 포함한 실제 적용 전 피해가 2배가 된다. 체력 20, 40m 제한, 2초 재활성 및 2026년 이동속도 50% 증가는 공식 패치 기준이다. 공식 문서에 절대 이동속도·폭발 반경·취약 지속시간이 공개되지 않아 현재 모델은 각각 8.25, 3.5m, 4초를 조정 가능한 상수로 둔다.

4맵 회귀 검증에서는 적 획득 1회, 추적 이동 8틱, 폭발 1회, 취약 적용 1명과 실제 2배 피해 3건을 확인했다. 진단 이벤트 `alarmbotAcquire`, `alarmbotMove`, `alarmbotTrigger`, `vulnerableApplied`로 모든 단계를 추적할 수 있다.

Alarmbot 적용 후 40맵·810라운드 분포 검증은 통과 14개·경고 2개·실패 0개다. 전멸 71.1%, 폭발 13.7%, 해체 11.5%, 시간 종료 3.7%이며 ADR은 93.5, 요원 피해는 847회·9,407이다. 남은 경고는 ADR과 해체 승률이며, 결과 비율을 직접 보정하지 않고 이후 Lockdown 및 리테이크 상호작용까지 구현한 뒤 함께 교정한다.

Killjoy Lockdown은 시전자 위치에 체력 200의 파괴 가능한 장치로 설치된다. 13초 준비와 0.15초 펄스 지연이 끝날 때까지 반경 안의 적은 두 가지 대응을 한다. 가까이서 장치가 보이는 한 명은 총기 거리별 실제 몸통 피해로 장치를 공격하고, 나머지는 내비게이션을 이용해 범위 밖의 가장 가까운 이동 가능 지점으로 대피한다. 장치 HP가 0이 되면 펄스 없이 파괴된다.

펄스 순간 범위 안에 남은 적은 약 8초 동안 구금된다. 구금 상태에서는 선수 판단이 사격을 선택해도 실제 사격이 생성되지 않고, 스킬도 사용할 수 없으며 이동속도는 모델 상수 25%로 제한된다. 공식 기준은 궁극기 9포인트, 체력 200, 13초 준비, 0.15초 펄스 지연과 약 8초 구금이다. 정확한 범위와 구금 이동 배율은 공식 문서에 공개되지 않아 각각 32.5m와 25%로 분리해 관리한다.

중계 화면에는 준비 중 Lockdown 반경과 충전 장치를 표시하고, 파괴되면 반경을 즉시 제거한다. 발동 시 구금 인원과 각 구금 선수를 해설에 표시한다. 4맵 회귀에서는 장치 경쟁 1회, 대피 6회, 펄스 3회, 구금 3회와 장치 피해 2회를 확인했으며, 독립 파괴 검증에서는 누적 200 피해에서만 장치가 파괴되는 것을 확인했다.

Lockdown 적용 후 40맵·809라운드 분포 검증은 통과 14개·경고 2개·실패 0개다. 전멸 70.7%, 폭발 13.1%, 해체 12.0%, 시간 종료 4.2%이며 ADR은 93.7, 요원 피해는 846회·9,287.5다. Alarmbot 기준과 비교해 해체 승률은 11.5%에서 12.0%로 소폭 개선됐으며 남은 경고는 ADR과 해체 승률이다.

### Omen 공간 스킬

Omen의 Paranoia는 벽과 관계없이 직선 폭 안의 적에게 투사체 도달 시간 뒤 2초 근시를 적용한다. 현재 공식 속도 20m/s와 최대 거리 25m를 사용하며, 근시 상태에서는 인지·교전 시야가 모델 상수 7m로 줄어든다. Shrouded Step은 0.7초 준비 후 이동 가능한 15m 이내 후보 중 전술 목적지에 가깝고 적에게 덜 노출된 위치를 고른다.

From the Shadows는 4초 채널 동안 이동과 사격을 멈추고 전역 목적지로 이동한다. 채널 도중 사망·구금되거나 라운드가 끝나면 취소되고, 목적지를 적이 근거리에서 지키면 그림자 형상이 파괴된 것으로 처리해 원위치에 남는다. 시작·완료·취소와 취소 사유는 모두 진단 이벤트에 기록한다.

Dark Cover는 15초 동안 실제 시야선을 가리는 공간 오브젝트다. 같은 연막 안의 근접 교전은 허용하지만 연막에 들어가거나 빠져나오거나 관통하는 시야는 차단한다. 기본 1개는 무료이며 두 번째 충전은 150 크레드, 재충전은 40초다. 공식 문서에 안정적으로 공개되지 않은 연막 반경은 4.5m 모델 상수로 `src/core/ability-objects.js`에 분리했다. 4맵 회귀에서는 연막 시야 차단 941쌍, Paranoia 근시 6회, Shrouded Step 완료 18회, From the Shadows 완료·취소 각 1회를 확인했다.

Omen 적용 후 어시스트 기여 원장도 실제 시간 구간에 맞췄다. 피해 어시스트는 최근 10초 안에 들어간 피해만 합산하며, 근시·구금은 효과 종료 후 3초, 연막 이탈은 2초의 후속 인정 시간을 가진다. 각 킬의 `assistDetails`에는 피해량 또는 스킬명, 마지막 기여 시각과 어시스트 만료 시각을 남긴다.

교정 후 40맵·785라운드 분포 검증은 통과 14개·경고 2개·실패 0개다. APR은 0.2424에서 0.2468로 올라 허용 범위에 진입했고, 남은 경고는 ADR 93.35와 해체 승리 12.10%다. 결과 확률을 직접 보정하지 않고 실제 기여 시간만 바로잡은 결과다.

### Breach 공간 스킬

Breach의 Flashpoint는 벽을 통과하는 직선 범위에서 투사체 도달 시간 뒤 2.25초 섬광을 적용한다. Fault Line은 시전자 8m 앞부터 폭 8m 직선 구역을 예고하고 1.1초 뒤 2.5초 기절을 적용하며, 2026년 기준 시그니처 재사용 대기시간은 50초다. 기절 상태는 이동속도와 사격 정확도·연사 복구를 낮추고 효과 종료 후 3초까지 유틸리티 어시스트가 인정된다.

Rolling Thunder는 8m 앞에서 시작해 폭 18m의 파동이 순차적으로 진행되며 적중 대상에게 4초 기절을 적용한다. 궁극기 비용은 8포인트다. Aftershock는 고정된 벽 너머 구역에서 0.6초 간격으로 80 피해를 두 번 발생시킨다. 경고 구역 안 선수는 폭발 전 내비게이션상 가장 가까운 안전 지점으로 이탈하고, 늦거나 경로가 막힌 선수만 피해를 받는다. 피해는 적 선수뿐 아니라 범위 안의 파괴 가능한 적 스킬 오브젝트에도 적용된다.

4맵 회귀에서는 Flashpoint 4회·섬광 6명, 직선 기절 4회·적용 6명, Aftershock 9회·18폭발·247 피해를 확인했다. Breach 추가로 드러난 공격 포메이션 왕복을 막기 위해 최초 진형 이후 라운드당 최대 두 번만 변경하도록 제한하고, 거절된 변경은 진단 이벤트로 남긴다.

Breach 적용 후 40맵·796라운드 분포 검증은 통과 14개·경고 2개·실패 0개다. APR 0.2461은 허용 범위를 유지했고, ADR 92.79와 해체 승리 10.80%가 경고다. Breach의 공간 차단으로 수비 리테이크가 더 어려워진 결과이므로 승리 확률을 직접 보정하지 않고, 수비가 섬광·기절 종료를 기다린 뒤 클리어러와 해체 담당을 다시 합류시키는 판단을 다음 교정 대상으로 둔다.

### 리테이크 유틸리티 대기

후설치 수비가 근시·섬광·기절을 맞으면 `src/core/tactics/retake-utility.js`가 스파이크 시간과 효과 종료 시각을 비교한다. 남은 시간이 `해체 7초 + 남은 효과 시간 + 안전 여유 3초`보다 충분하면 클리어러와 해체 담당이 현재 진입을 멈추고, 적중 선수는 가까운 엄폐로 이동한다. 효과가 끝나면 기존 진입 목적지를 복원해 팀 단위로 재개한다. 이미 시간이 부족하면 유틸리티를 감수하고 강행한다.

대기 시작·추가 효과에 따른 연장·재개·시간 부족 강행·라운드 종료 취소는 각각 `retakeUtilityWait`, `retakeUtilityResume`, `retakeUtilityForce`, `retakeUtilityWaitCancel` 이벤트로 기록한다. 해체 중 적중하면 진행을 즉시 멈추고 기존 해체 체크포인트만 보존한다. 공격팀도 후설치에서 남은 섬광·기절과 적 접촉이 있으면 이를 리테이크 차단 목적으로 사용한다.

적용 후 40맵·796라운드 분포 검증은 통과 14개·경고 2개·실패 0개다. 평균 라운드는 19.9, 전멸 68.34%, 폭발 15.70%, 해체 10.80%, 시간 종료 5.15%이며 ADR은 92.69다. 4맵 에이전트 회귀 표본에서는 실제 후설치 적중이 발생하지 않아 대기 이벤트가 0회였지만, 별도의 고정 시나리오가 대기 시작 → 추가 유틸 연장 → 유지 → 재개 → 두 번째 대기 → 시간 부족 강행 또는 라운드 종료 취소의 전체 상태 전환을 검증한다. 시간 부족 강행 시 기존 대기가 남아 있던 오류도 수정해 즉시 리테이크를 재개한다.

### Raze 폭발 스킬 1차 구현

Paint Shells는 주 폭발 반경 5.5m와 자탄 반경 5.25m를 사용한다. 주 폭발 뒤 네 자탄이 1초 후 서로 다른 위치에서 폭발하고, 각 폭발은 중심 55에서 가장자리 최소 1까지 거리 감쇠한다. Showstopper는 1.4초 장착과 투사체 이동 뒤 반경 피해를 발생시킨다. 두 스킬의 경고 범위에 있는 선수는 내비게이션상 가까운 안전 지점으로 이탈하며, 벽을 통과해 피하지 않는다. Showstopper의 공개되지 않은 현재 정확한 폭발 반경은 8m 모델 상수다.

Boom Bot은 5초 동안 내비게이션 경로를 순찰하고 시야 안의 적을 획득하면 추적한다. 적이 폭발 반경에 들어오면 거리 감쇠 피해를 주며, 도달 전에 총기로 파괴할 수 있다. Blast Pack은 사용 즉시 Raze에게 7m 진입 경로를 만들지만 적 피해는 1.5초 완전 무장 뒤에만 발생한다. 상대가 무장 전에 파괴하면 피해나 넉백이 생기지 않는다. 공식 공개값이 아닌 Boom Bot 체력·절대 순찰/추적 속도·추적 반경과 Blast Pack 반경은 조정 가능한 모델 상수다.

Raze 오브젝트 파괴는 전역 확률 난수를 사용하지 않고 0.5초 간격의 실제 총기 몸통 피해를 누적한다. 새 오브젝트가 추가될 때 무관한 이후 교전 난수열까지 밀려 연장률이 비정상적으로 변하던 문제를 막기 위한 구조다. 4맵 회귀에서 Boom Bot 이동·적 획득과 파괴, Blast Pack 기동·무장 후 폭발을 확인했다.

Raze 네 스킬 완료 후 40맵·832라운드 분포는 통과 13개·경고 3개·실패 0개다. ADR 93.39, APR 0.2457, 연장률 17.5%가 경고이며 APR은 허용 기준 15%에서 0.1%p만 벗어났다. 실패로 치솟았던 연장률 20%는 결정론적 오브젝트 파괴로 교정했다.

### ADR 원인 진단

`npm run diagnose:adr`은 경기 결과 비교와 분리된 ADR 전용 진단을 실행하고 `runtime_2026/data/adr-diagnostic.json`을 생성한다. `-- --matches=10`처럼 표본 수를 줄일 수 있다. 총기·스킬·HP·보호막·치명·비치명 피해, 발사 및 명중 탄환, 무교전 라운드, 첫·마지막 교전 시각, 이탈, 회복과 생존자의 잔여 체력을 각각 기록한다.

40맵 이벤트 재합산 피해는 선수 라운드당 94.14로 기존 박스스코어 ADR과 거의 같았다. 따라서 낮은 ADR은 통계 계산 오류가 아니다. 피해의 95.9%가 총기이고 모든 라운드에 사격·피해·킬이 있어 미구현 스킬이나 무교전 라운드가 주원인도 아니다. 탄환 명중률은 33.3%, 사격 행동의 완전 빗나감은 35.5%, 라운드당 전투 이탈은 5.06회였다.

생존 집계를 수정한 10맵 표본에서는 평균 3.12명이 살아남았고 생존자는 평균 HP 88.7·보호막 27.8을 보유했다. 라운드당 363.1의 생존 체력이 소비되지 않았다. 실제 KPR과의 차이보다 ADR 차이가 훨씬 크므로, 다음 교정은 전체 명중률이나 피해량을 일괄 상승시키지 않고 엄폐 이탈 전 견제 사격, 교차 사격과 트레이드 과정에서 승리팀 생존자에게 들어가는 비치명 교환 피해를 보완한다.

엄폐로 이탈하는 선수는 적이 여전히 벽 없이 보이고 무기가 준비됐을 때 한 발의 견제 사격을 수행한다. 정확도는 선수의 침착성·인지력·노출 인원·이동 여부에 따라 10~34%로 제한하며, 적중하면 기존 총기의 부위·거리 피해와 보호막 규칙을 그대로 사용한다. 견제 사격 난수는 맵·시각·참여 선수로 만든 독립 스트림에서 소비해 이후 주 교전 난수열을 바꾸지 않는다.

10맵 진단에서 견제 사격은 1,860회 중 245회 적중해 11,817 피해, 선수 라운드당 5.55 피해를 만들었다. 전체 비치명 피해 비중은 54.9%에서 57.9%, 라운드당 미소비 생존 체력은 363.1에서 329.6으로 개선됐다. 최종 40맵·804라운드 분포는 통과 14개·경고 2개·실패 0개이며 ADR은 93.39에서 94.26으로 상승했다. 연장률과 APR 경고가 해소됐고 남은 경고는 ADR과 해체 승리 12.06%다.

ADR 진단 v2는 트레이드, 교차각, 집중 사격의 발사·탄환·명중·치명/비치명 피해를 따로 기록한다. 세 조건은 동시에 성립할 수 있으므로 합산 가능한 독립 항목이 아니라 겹치는 진단 태그다. 기존 교차 사격 판정은 같은 적을 볼 수 있는 근처 아군을 모두 교차각으로 보아 선수 라운드당 47.25 피해를 잘못 분류했다. `trade-v2-angle`부터는 표적 기준 사선이 32도 이상 벌어지고 지원자가 표적 18 거리 안에서 직접 시야를 확보한 경우만 교차각으로 인정한다. 같은 통로에 겹친 아군은 일반 지원과 트레이드만 유지한다.

동일 10맵 표본에서 각도 기반 교차 사격은 236회·656발·268적중, 9,249 피해와 59.36% 비치명 피해를 기록했다. 트레이드는 376회·12,784.5 피해, 집중 사격은 872회·29,809.5 피해였으므로 별도 인공 피해를 추가하지 않았다. 최종 40맵·819라운드 분포는 통과 15개·경고 1개·실패 0개이며 ADR 94.67만 경고로 남았다.

ADR 진단 v3는 생존 체력을 승리팀·패배팀, 승리 방식, 승리팀 생존 인원별로 분리하고 요원·스킬별 사용 및 실제 피해도 함께 기록한다. 10맵 기준 라운드당 잔존 활력 351.02 중 승리팀이 323.07, 패배팀이 27.95였다. 따라서 낮은 ADR을 패배팀 생존자에게 임의 피해를 추가하는 방식으로 교정하지 않는다. 실제 KPR은 VCT보다 약 5.4% 낮지만 ADR은 21.9% 낮아, 아직 피해가 없는 자주 쓰이는 스킬과 깨끗한 다인 생존 승리의 교환 피해를 따로 감사한다.

미감사 요원 사용량에서는 Viper가 10맵 171회로 가장 높았고 Snake Bite가 84회를 차지했다. Snake Bite는 1회·300크레딧·6.5초의 실제 산성 지대로 변경했다. 지대 안에서는 초당 12.5 기본 피해와 2배 취약이 함께 적용되어 초당 25 피해가 되고, 벗어난 뒤 취약은 2초 유지된다. 투사 후 Viper가 사망해도 지대는 만료 시각까지 남고, 벽 너머에는 피해를 주지 않으며 생존자는 위험 지역 이탈 판단을 수행한다. 적용 후 동일 10맵 표본에서는 98회 사용·1,809 피해를 기록했고 전체 이벤트 ADR은 95.04에서 95.15로 상승했다.

Poison Cloud와 Toxic Screen은 하나의 연료 저장소를 공유한다. 연료 30% 이상에서만 켤 수 있고, 단독 사용 최대 12초와 비활성화 후 5초 재사용 대기를 적용한다. 두 장치를 동시에 켜도 하나만 켰을 때와 같은 속도로 연료를 소모한다. 적이 독 영역에 처음 닿으면 10 Decay를 받고 이후 초당 10씩 체력이 임시 감소하며, 영역을 벗어난 1.5초 뒤부터 회복한다. Decay는 체력을 1 아래로 낮추지 않고 일반 피해나 ADR로 집계하지 않는다. 10맵 진단에서는 551회·1,001 Decay와 419회·825 회복을 별도 기록했다.

Viper's Pit은 8포인트 궁극기로 바이퍼 현재 위치를 중심으로 생성한다. 바이퍼가 영역 밖에 머무르면 8초 무결성이 감소하고, 안으로 돌아오면 25초에 걸쳐 전체 무결성을 회복한다. 바이퍼가 사망하거나 무결성이 0이 되면 즉시 붕괴한다. 적에게만 근시와 동일한 비치명·회복 가능 Decay를 적용하며, 궁극기와 일반 독 연막의 Decay 기여는 진단에서 각각 분리한다. 10맵에서는 Toxic Screen 918, Poison Cloud 176, Viper's Pit 421로 총 1,515의 임시 체력 감소가 발생했고 1,150이 회복됐다. 이 값은 ADR 94.61에 포함되지 않는다.

Viper's Pit의 범위는 단순 원형 거리뿐 아니라 맵 내비게이션 연결 거리도 검사한다. 원 안에 있더라도 벽을 돌아가는 실제 경로가 궁 범위를 초과하거나 도달할 수 없으면 근시와 Decay를 적용하지 않는다. 4맵 회귀에서 이런 벽 너머 오판 6건을 찾아 차단했다.

Chamber 감사는 Trademark와 Rendezvous부터 적용했다. Trademark는 200크레딧·1개, 20 HP, 4초 준비, 10 거리 감지와 0.9초 경고 후 6 반경에 4초 감속을 부여한다. 현재 규칙에 따라 Chamber와의 거리 제한은 없다. Rendezvous는 50 HP 단일 앵커와 18 거리 범위를 사용하며, Chamber가 범위 안에서 교전하면 앵커로 복귀하고 0.7초 재무장과 30초 재사용 대기를 적용한다. 통합 후 4맵 회귀에서는 Trademark 2회 감지·1회 폭발과 Rendezvous 3회 교전 복귀를 확인했다. 해당 표본의 적은 경고 중 이탈해 감속을 피했다.

Headhunter는 탄환당 100크레딧으로 최대 8발을 구매하며 라운드 계획에 잡힌 탄을 모두 잃지 않고 실제 발사한 수만 차감한다. 피해는 거리와 무관하게 머리 159, 몸 55, 다리 46이다. Tour De Force는 8 궁극기 포인트로 5발을 장전하고 초당 0.9발로 발사하며 Operator와 같은 255/150/120 피해를 준다. 처치 시 해당 위치에 4초 감속 지대를 생성한다. 감속 지대 반경 6과 이동 배율 0.5는 공개되지 않은 공간을 위한 조정 가능한 시뮬레이션 상수다. Trademark와 Rendezvous의 20/50 HP도 확률 파괴가 아니라 실제 총기 몸통 피해가 누적되어 소진될 때만 파괴된다.

분포 검증 보고서는 `simulation.abilityUsage.byAgent`, `byAbility`에 실제 발동 횟수를 기록한다. Chamber 적용 후 40맵에서는 17회 무기 장착, 38발 발사, Tour De Force 처치 감속장 18개와 실제 감속 12회를 확인했다. 전체 비교는 통과 14개·경고 2개·실패 0개이며 ADR 93.81과 연장률 2.5%가 남은 경고다.

Cypher Trapwire는 담당 사이트 초크에 길이 8의 선으로 배치된다. 적이 선을 통과하면 즉시 위치를 공유하고 2초 감속하며, 장치를 파괴하거나 범위를 벗어나지 못하면 1.5초 뒤 3초 기절한다. 발동 뒤 장치는 0.5초 후 다시 활성화된다. 장치 20 HP는 실제 총기 몸통 피해로만 감소한다. 선 길이·감지 폭·이탈 범위는 맵별 통로 좌표를 세밀하게 다듬을 때 조정할 모델 값이다.

Trapwire는 라운드 종료 때 `tripwireDiagnostic` 이벤트로 선의 양 끝점, 가장 가까이 접근한 적과 거리, 파괴자, 실제 발동 여부를 남긴다. 4맵 표본에서는 5개 중 2개가 선에 닿기 전 총으로 파괴됐고 나머지는 공격 경로가 다른 사이트를 향했다. Cyber Cage는 개당 100크레딧으로 최대 2개를 사용하며 7.25초 동안 반경 4.5의 실제 시야 차단 영역을 만든다. 반경은 맵 좌표계에 맞춘 조정 가능한 모델 상수다.

Spycam은 20 HP 설치형 정찰 장치다. 반경 25 안에서 벽으로 가려지지 않은 적을 추적 다트로 태그해 2초 공개하며 다트는 6초 후 다시 준비된다. 파괴되면 실제 45초 재사용 대기에 들어간다. Neural Theft는 6 궁극기 포인트를 사용하고 18 거리 안의 적 시체가 있을 때만 발동한다. 발동 즉시와 4초 뒤에 생존한 모든 적의 위치를 팀 정보로 공유하며, 시체가 없으면 궁극기 포인트를 소비하지 않는다. 시야 반경과 공개 시간은 공간 시뮬레이션용 모델 상수다.

Cypher 전체 적용 후 40맵·812라운드 검증은 통과 15개·경고 1개·실패 0개다. 평균 라운드 20.3, 연장률 7.5%이며 전멸 66.13%, 폭발 16.01%, 해체 14.53%, 시간 종료 3.33%가 모두 허용 범위다. 스킬 사용은 Trapwire 186회, Cyber Cage 128회, Spycam 78회, Neural Theft 14회였다. 남은 분포 경고는 ADR 93.76 하나다.

Vyse는 네 스킬이 실제 공간·전투 상태에 연결되어 있다. Shear는 진입 감지 후 7.8초 벽으로 후속 인원을 지연시키며, Arc Rose는 25m 안에서 벽으로 가리지 않고 섬광을 바라보는 대상이 있을 때만 발동한다. Razorvine은 반경 6m에서 이동 속도를 50%로 낮추고 움직이는 대상에게 초당 15 피해를 주며, 생존자는 내비게이션상 가장 가까운 안전 지점으로 이탈한다. 배치 순간의 범용 직접 피해는 중복 적용하지 않는다.

Steel Garden은 3.4초 준비 후 반경 32m 안의 적 주무기를 8초간 사용 불가로 만든다. 모델에서는 해당 무기를 임시 보관하고 Classic으로 전환한 뒤 시간이 끝나면 원래 무기를 복원한다. 구매가 900 이상인 주무기와 Tour De Force가 대상이며 권총, Headhunter, Blade Storm은 제외한다. 거리·준비시간·지속시간처럼 공식 클라이언트에서 직접 읽기 어려운 값은 향후 패치 감사와 밸런스 검증을 위해 별도 모델 상수로 취급한다.

Vyse 적용 후 고정 seed 40맵·803라운드 검증은 통과 15개·경고 1개·실패 0개다. 스킬 사용은 Shear 89회, Arc Rose 84회, Razorvine 21회, Steel Garden 5회였으며 승리 방식 지표는 모두 허용 범위다. 남은 경고는 선수 ADR 94.06이다.

Sova는 Recon Bolt, Owl Drone, Shock Bolt, Hunter's Fury가 각각 독립적인 공간 이벤트로 동작한다. Recon Bolt는 60초 재사용 대기를 사용하며 선택한 사이트 내부에 착탄해 벽으로 가리지 않은 적을 반복 탐지한다. 공개 문서에 안정적인 탐지 반경이 없어 현재 32.5m를 조정 가능한 모델 상수로 사용한다. 다트는 20 HP이며 적이 파괴하면 이후 펄스가 중단된다.

Owl Drone은 7초 동안 Sova의 직접 행동을 묶고 내비게이션 경로로 적에게 접근한다. 8m 안에서 시야가 확보되면 한 대상에게 1초 간격의 추적 펄스 세 번을 남기며, 100 HP가 소진되면 조종이 즉시 끝난다. 이동속도 7m/s, 탐색 반경 30m와 태그 거리는 공개 패치 수치가 아닌 명시적 시뮬레이션 상수다.

Shock Bolt는 현재 150 크레드·최대 2개·최대 75 피해를 사용하며 0.8초 뒤 반경 8m 안에서 거리에 따라 최소 10까지 감쇠한다. Hunter's Fury는 8포인트를 소모해 0.9초 간격으로 80 피해 직선 빔 세 발을 발사하고 벽을 관통한다. 적중 대상은 1초간 공개되며 파괴 가능한 적 오브젝트에는 기본 피해의 50%만 적용한다. 만료된 오브젝트는 어떤 후속 스킬 피해로도 다시 파괴 처리되지 않는다.

Sova 적용 후 고정 seed 40맵·819라운드 검증은 통과 15개·경고 1개·실패 0개다. 사용량은 Recon Bolt 48회, Owl Drone 76회, Shock Bolt 149회, Hunter's Fury 13회이며 승리 방식은 모두 허용 범위다. 남은 경고는 선수 ADR 94.71이다.

Astra는 Gravity Well, Nova Pulse, Nebula가 서로 별도 탄약을 쓰는 대신 `astraStars` 공유 자원을 사용한다. 라운드 구매 단계에서 무료 별 1개를 먼저 받고, 추가 별은 개당 150크레딧으로 최대 5개까지 구매한다. 사용하지 않은 계획은 별 저장량으로 되돌아가며 한 라운드 총 소비량이 5개를 넘지 않는지 회귀 검증한다.

Gravity Well은 1.25초 준비 뒤 반경 4.75 안의 적을 2초간 끌어당기고 종료 시 남아 있는 적에게 2.5초 취약을 준다. Nova Pulse는 1초 준비 뒤 같은 반경에 2.5초 기절을 적용한다. Nebula는 14.25초 동안 시야를 차단한다. Cosmic Divide는 21초 동안 총탄과 발소리를 완전히 차단하지만 시야는 막지 않는다. 별 회수·회수 연막과 동일 효과의 한 라운드 다중 활성화는 아직 후속 구현 대상이다.

고정 seed 40맵·814라운드 검증에서 Astra는 Gravity Well 139회, Nova Pulse 111회, Nebula 112회, Cosmic Divide 33회 사용됐다. 통과 14개·경고 2개·실패 0개이며 승리 방식은 전멸 67.44%, 폭발 14.86%, 해체 14.25%, 시간 종료 3.44%다. 남은 경고는 ADR 94.01과 연장률 5.0%다.

### 시즌 경기 기록

정규시즌 일정의 각 경기에는 `regular-w{주차}-m{순번}` 형식의 안정적인 ID가 있다. 사용자 경기와 백그라운드 경기는 모두 같은 결과 반영 함수를 통해 승패, 맵 득실, 라운드 득실과 선수 박스스코어를 `ST.matchArchive`에 기록한다. 순위는 승수, 맵 득실, 라운드 득실, 상대전적, 팀명 순으로 결정한다.

시즌 아카이브에는 장기 통계에 필요한 경기·맵 요약과 선수 박스스코어를 남긴다. 중계 재생용 좌표 트랙은 모든 백그라운드 경기에 중복 저장하지 않는다.

```powershell
npm run verify:season
npm run verify:tournament
```

게임의 2026 리그 Stage는 실제 VCT의 12팀과 상위 8팀 플레이오프 구조를 참고한다. 사용자 요청에 따라 Alpha/Omega 두 그룹은 사용하지 않고 12팀 전체 단일 라운드 로빈으로 구성한다. 정규시즌 상위 8팀은 더블 엘리미네이션에 진출하며 일반 경기는 Bo3, 패자조 결승과 결승은 Bo5다. 대회 화면에서 우리 팀 일정, 전체 일정과 승자조·패자조 대진표를 확인할 수 있다.

대회 구조는 `src/core/tournament.js`, 진행 상태는 `ST.competition`, 완료 경기 요약은 `ST.matchArchive`에서 관리한다.

### 경기 진행 제어와 타임아웃

관전 경기에서는 다음 라운드 전에 정지하거나, 한 라운드만 진행하거나, 자동 진행을 재개할 수 있다. 타임아웃은 경기 중 전술 성향을 다시 정하는 감독 개입 기능이다.

- 정규 구간에서는 팀마다 공격·수비 합산 총 2회
- 진영 변경 시 남은 횟수 유지
- 연장에서는 2라운드로 구성된 연장 구간마다 팀별 1회
- 연장 구간의 남은 횟수는 다음 구간으로 이월하지 않음
- 변경한 전술은 다음 라운드부터 적용
- 상대 AI도 같은 횟수 규칙 안에서 연패와 점수 차를 보고 타임아웃을 판단
- 사용 시점과 변경 전·후 전술 정책을 맵 결과 로그에 저장

타임아웃 규칙은 다음 명령으로 별도 검증한다.

```powershell
npm run verify:timeouts
```

남은 경기 논리 문제와 구현 순서는 [PLAN.md](./PLAN.md)에서 관리한다.
### Sage 공식 규칙 반영

Sage의 Barrier Orb, Slow Orb, Healing Orb, Resurrection을 독립적인 공간·상태 규칙으로 구현했다. Barrier Orb는 15m 시전 판단, 400 초기 내구도, 3.3초 후 피해를 보존한 채 800까지 강화되는 파괴 가능 장벽이며 시야·탄환·이동 경로를 막는다. 지속시간은 30초다. Slow Orb는 200 크레드, 2회, 7초 동안 반경 내 아군과 적군의 이동 속도를 50%로 낮춘다.

Healing Orb는 45초 재사용 대기시간을 가지며 가장 체력이 낮은 가시권 아군 또는 Sage 자신에게 5초 동안 최대 100 HP를 회복한다. Resurrection은 8 궁극기 포인트, 12m 거리와 시야 조건을 확인한 뒤 3.3초 채널링하여 사망한 아군을 100 HP·보호막 0으로 복귀시킨다. 장벽 길이·폭과 초기 내구도처럼 Riot 공식 문서에 현재 완전한 수치가 공개되지 않은 값은 `src/core/ability-objects.js`의 조정 가능한 모델 상수로 격리했다.

고정 시드 요원 회귀검증에서는 장벽 배치·강화·경로 차단·실제 피격, 둔화 진입, 지속 치유, 부활 시작·완료를 각각 검사한다.

Sage 반영 후 전체 VCT 분포 검증은 40맵·821라운드에서 통과 14, 경고 2, 실패 0을 기록했다. 경고는 기존과 같은 ADR 94.24와 연장 진입률 5%이며, Sage는 23회 선택되어 전체 표본에도 포함됐다. 프로덕션 빌드도 통과했다.
### Clove 공식 규칙 반영

Clove의 Pick-Me-Up, Meddle, Ruse, Not Dead Yet을 독립 생명주기로 구현했다. Pick-Me-Up은 Clove가 최근 6초 안에 피해를 준 적의 처치에 관여했을 때만 사용하며, 최대 총 생존력 150 범위에서 10초 임시 체력과 3초 이동 가속을 얻는다. 임시 체력은 실제 피격에서 먼저 소모되고 남은 값은 시간이 끝나면 사라진다.

Meddle은 착지 후 0.75초에 폭발하여 반경 내 적에게 최대 90의 비치명 Decay를 5초간 부여하고 이후 회복시킨다. Ruse는 2회 연막과 40초 재사용 대기시간을 사용하며 Clove가 죽은 뒤에도 시체 주변 15m 안에서 13.5초 연막을 배치할 수 있다. Not Dead Yet은 8포인트를 소모해 사망 직후 3초 안에 100 HP로 복귀하며, 12초 안에 킬 또는 최근 6초 피해 어시스트를 얻지 못하면 다시 사망한다. 복귀 직후 2초 비물질 상태와 0.8초 재무장 시간을 모델링했다.

Riot 공식 문서에 현재 수치가 완전히 공개되지 않은 Meddle 반경·Decay량, Ruse 반경·사망 후 범위, 부활 세부 시간은 `src/core/ability-objects.js`와 Clove 전용 상태 상수로 분리했다.

Clove 반영 후 전체 VCT 분포 검증은 40맵·811라운드에서 통과 14, 경고 2, 실패 0을 기록했다. Clove는 총 24회 스킬을 사용했으며 Ruse 13회, Meddle 5회, Pick-Me-Up 4회, Not Dead Yet 2회다. 경고는 ADR 94.30과 연장 진입률 2.5%이고 프로덕션 빌드도 통과했다.

### Deadlock 공식 규칙 반영

Deadlock의 GravNet, Sonic Sensor, Barrier Mesh, Annihilation을 독립 공간·상태 규칙으로 구현했다. GravNet은 현재 13m 전체 크기와 50초 재사용 대기시간을 사용하는 시그니처이며, 적을 포획해 이동을 제한하고 해제 행동 뒤 정상 상태로 돌린다. Sonic Sensor는 수비 준비 단계에 배치되고 단순 접근이 아니라 감지 범위 안의 달리기나 총성에 반응해 지연 기절을 발생시킨다.

Barrier Mesh는 400 크레딧 일반 스킬이며 Sage 장벽과 달리 시야와 탄환을 막지 않고 이동 경로만 차단한다. 중심 노드와 네 개 팔의 정확한 세부 형상은 현재 조정 가능한 방사형 모델 상수로 격리했다. Annihilation은 처음 접촉한 적을 코쿤에 가두어 시전자 쪽으로 끌고 오며, 가까운 아군이 구조하지 못한 채 종점이나 제한시간에 도달하면 처형한다.

고정 시드 회귀에서는 GravNet 10회, Sonic Sensor 6회, Barrier Mesh 1회의 실제 사용과 상태 해제를 확인했다. 전체 VCT 분포 검증은 40맵·805라운드에서 통과 14, 경고 2, 실패 0을 기록했고 Deadlock은 GravNet 6회, Sonic Sensor 5회, Barrier Mesh 1회를 사용했다. 경고는 기존 ADR 94.49와 연장 진입률 2.5%이며 프로덕션 빌드도 통과했다.

### Harbor 리워크 규칙 반영

Harbor는 2025년 11.10 리워크 이후의 현행 구성을 사용한다. 기존 Cascade를 제거하고 Storm Surge, High Tide, Cove, Reckoning 순서로 스킬 데이터를 교체했다. Storm Surge는 짧은 지연 뒤 범위 안 적에게 근시와 둔화를 적용하고, 실제 적중 여부를 오디오 진단 이벤트로 남긴다.

High Tide는 300 크레딧 일반 스킬이며 최대 60m 물 장벽으로 시야를 차단한다. 장벽을 통과한 아군과 적군 모두 짧게 둔화된다. Cove는 30초 재사용 대기시간의 시그니처로, 19.25초 연막은 항상 시야를 차단하고 재활성화한 680 HP 방어막만 탄환을 차단한다. 방어막이 파괴되어도 연막의 남은 생명주기는 유지된다.

Reckoning은 전진하는 물결에 닿은 적에게 근시와 둔화를 적용한다. 다수의 적을 포착하면 재활성화 판단으로 물결을 정지시키고 해당 위치에서 7초간 유지한다. 파도 폭·속도와 세부 디버프 지속시간처럼 공식 문서에 완전한 수치가 없는 값은 `src/core/ability-objects.js`에 조정 가능한 모델 상수로 격리했다.

5맵 고정 회귀에서 Storm Surge 8회·적중 4명, High Tide 3회·통과 둔화 8회, Cove 8회·방어막 피해 680 및 파괴 1회, Reckoning 2회·적중 5명·정지 1회를 확인했다. 전체 VCT 분포 검증은 40맵·805라운드에서 통과 14, 경고 2, 실패 0이며 기존 ADR 94.49와 연장 진입률 2.5%만 경고로 남았다.
